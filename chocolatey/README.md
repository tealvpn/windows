# Teal VPN on Chocolatey

Package source for https://community.chocolatey.org/packages/teal-vpn (`choco install teal-vpn`).
Built and pushed by `tern/scripts/choco_package.py` from windows/latest.json after every Windows release; the package
downloads the signed installer from the GitHub release of the same version (SHA-256 pinned) and runs it with `/quiet`.
